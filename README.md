# OvineScan 🐑🔬

A web-based application for early detection of sheep diseases through image analysis, powered by a machine learning model. This project was developed by the CoreSight team.

![OvineScan Demo](https://via.placeholder.com/800x400.png?text=Ganti+dengan+Screenshot+Aplikasi+Anda)
## 📜 About The Project

Traditional methods for diagnosing sheep diseases can be time-consuming, require expert knowledge on-site, and may not be accessible to all farmers. OvineScan aims to solve this problem by providing an easy-to-use platform where farmers can get an initial analysis of potential diseases simply by uploading a photo of their sheep. Our goal is to empower farmers with a fast, accessible, and data-driven tool for better livestock health management.

## ✨ Key Features

-   **Image Upload:** Easily upload sheep photos from any device.
-   **AI-Powered Analysis:** Utilizes a Convolutional Neural Network (CNN) model to analyze images.
-   **Instant Results:** Provides a list of potential diseases with confidence scores.
-   **Disease Information:** Offers basic information and preliminary handling suggestions for detected diseases.
-   **History:** Users can track their past analysis history.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

-   [Contoh: Node.js v18.x or higher]
-   [Contoh: Python 3.9 or higher]
-   [Contoh: npm, pip]

### Installation

1.  Clone the repo
    ```sh
    git clone [https://github.com/username/ovinescan.git](https://github.com/username/ovinescan.git)
    ```
2.  Install NPM packages for the frontend
    ```sh
    cd client
    npm install
    ```
3.  Install Python packages for the backend
    ```sh
    cd server
    pip install -r requirements.txt
    ```
4.  Configure your environment variables by creating a `.env` file.
    ```
    DATABASE_URL="your_database_url"
    ```
5.  Run the application.
    ```sh
    # Jalankan backend (di folder server)
    python app.py
    # Jalankan frontend (di folder client)
    npm start
    ```
